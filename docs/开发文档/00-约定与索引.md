## 3. 全局约定

### 3.1 分层职责（谁校验、谁报错）

| 层 | 负责 | 不负责 |
|---|---|---|
| `apps/api` | 请求形状校验（pydantic）、鉴权、权限、`If-Match`、错误封装、`request_id` | 业务判断、跨表约束 |
| `service` | 事务边界、业务规则（预算、状态机、权限内的资源归属） | HTTP 概念、SQL 细节 |
| `domain` | 纯规则：时序闭合、台词内嵌、槽位连续、成本计算 | IO、DB、网络 |
| `agent` | 循环、上下文组装、Skill/lesson 召回、归因 | 不碰 HTTP、不碰 DB 直连 |
| `providers` | 一次外部调用 + 预算 + 用量回报 | 不认识 clip/project |
| `jobs` | 状态机、幂等、抢占、超时 | 业务语义 |

原则：**同一规则只在 domain 里写一次**；api 只做形状，service 只做编排。

### 3.2 时间

- 一律 **UTC**，API 用 ISO 8601 带毫秒和 `Z`：`2026-10-18T10:20:30.123Z`。
- DB 列 `DATETIME(3)`，存 UTC，**不用 `TIMESTAMP`**。
- 前端负责转本地时区并格式化；任何跨度计算用后端给出的 `duration_ms` / `elapsed_ms`，前端不做时区减法。

### 3.3 金额与用量

| 概念 | 存储 | 传输 | 说明 |
|---|---|---|---|
| 金额 | `DECIMAL(12,6)` 元 | **string**，如 `"2.270000"` | 绝不用 float。前端 `Number()` 仅供显示 |
| token | `INT UNSIGNED` | number | 不足 1 记 0 |
| 视频时长 | `DECIMAL(6,2)` 秒 | string，如 `"12.04"` | 上游给毫秒精度，统一截到 0.01s |
| 延迟 | `INT UNSIGNED` 毫秒 | number | |

**成本口径**：`cost = unit_price × (video_seconds | tokens)`，四舍五入到 6 位小数并落库；台账只认 `revision.cost`，不重算。

### 3.4 ID

- 主键统一 `BIGINT UNSIGNED AUTO_INCREMENT`，API 直接暴露该数字（`/api/v1/clips/123`）。
- **不做**对外 ID/内部 ID 双轨映射：Demo 无需隐藏计数，多一层映射只会多一处出错。取舍记录在此，面试可讲。
- `idem_key` 例外，用 `CHAR(64)`（sha256 hex）。
- 组合唯一键见 `01`。

### 3.5 枚举

- DB 存 `VARCHAR(24)` + `CHECK` 约束；Python 用 `StrEnum`；TS 用 `as const` 联合类型。
- **新增枚举值 = 一次 DDL**（加 `CHECK`），不做"未知值兜底"。原因：静默兜底会让状态机进入非法态。
- 全部枚举见 `01` §2。

### 3.6 分页

| 对象 | 方式 | 参数 |
|---|---|---|
| `episodes` / `clips` / `members` | **不分页**（受剧本规模约束，有硬上限） | — |
| `revision` / `job` / `asset` / `lesson` | **游标**：按 `id DESC` | `limit`(1–200,默认50) + `cursor`(上一页最小 id) |

响应形状：

```json
{ "items": [ ... ], "next_cursor": 1234 }
```

`next_cursor` 为 `null` 表示到底。**不返回 total**（避免 `COUNT(*)`；前端显示"加载更多"而非"共 N 条"）。

### 3.7 错误封装

成功：直接返回资源或 `{items, next_cursor}`，**不套 `{code,data}`** —— HTTP 状态码已经承载语义。

失败：**唯一形状**

```json
{
  "error": {
    "code": "BUDGET_EXCEEDED",
    "message": "本次生成预算已用尽",
    "detail": { "budget_limit": "12.000000", "cost_used": "12.040000" },
    "request_id": "req_01J9Z8K2QW3E"
  }
}
```

- `message`：**给人看的中文**，可直接上 UI。
- `detail`：给开发和 UI 分支用，**可能为空对象**；provider 原始报文只进 `detail.raw` 与服务端日志，不拼进 `message`。
- `request_id`：同 `X-Request-Id` 响应头，贯穿日志与 `job.error_detail`。
- 完整错误码见 `02` §4。

### 3.8 幂等

- **仅"会花钱"的端点强制** `Idempotency-Key` 头：`POST /clips/{id}/generate`、`POST /clips/{id}/reroll`、`steps/*/run`（5 条）。清单以 `02` §3 的 `I` 标记为准。
- 语义：同 key + 同 body → 返回首次结果，HTTP 200，响应头 `Idempotency-Replayed: true`；同 key + 不同 body → `409 IDEM_KEY_REUSED`。
- 实现：key 即 `job.idem_key`，唯一索引兜底。存的是 `sha256(user_id:头值)`，**`user_id` 参与 hash** → 全局唯一索引即可隔离用户，客户端可用任意字符串而互不干扰（`03` §8.1）。
- **校验时机在 `If-Match` 之前**：命中即重放，不再校验版本/预算（`02` §5.3）—— 否则超时重试永远 412，幂等键等于不存在。
- **`POST /jobs/{jid}/retry` 不带幂等键**：它是同一行的状态迁移，重复调用的答案是 `JOB_STATE_INVALID`（`03` §8.2）。
- **其余写接口不做全局幂等**，靠 `If-Match`（§3.9）与 HTTP 语义（PATCH/PUT 天然幂等）保证。不做"万能幂等中间件"：那需要存全量响应，收益远小于复杂度。

### 3.9 两套并发控制（别混）

| 机制 | 目的 | 粒度 | 失败表现 |
|---|---|---|---|
| `lock_row`（TTL 10s） | **协作提示**："别人正在编辑这个 clip"，UI 显示灰条 | 资源级，软锁，可被夺 | 不影响写入，只提示 |
| `If-Match`（`etag` = 资源 `version`） | **强制冲突检测**：防止用旧数据覆盖新数据 | 行级，硬校验 | `412 STALE_VERSION` |

规则：**所有 PATCH 必须带 `If-Match`**；锁只用于"编辑中"提示，**任何写操作都不因锁而失败**。锁是提示不是权限。

### 3.10 日志与追踪

每条服务端日志必带：`request_id`、`job_id`（可空）、`user_id`（可空）、`project_id`（可空）。
对外接口**不打印** prompt 全文（可能含用户剧本）；只打 `prompt_sha256` 与前 80 字符摘要。

## 4. 术语

| 词 | 含义 |
|---|---|
| 项目 / project | 一部剧 |
| 集 / episode | 一集，一集 = 一组 clip |
| 片段 / clip | 一次视频生成的最小单位，≤15 s，对应一个 Seedance 片段 |
| 镜头 / shot | clip 内部的时间切片，`shots_json` 的一项 |
| 槽位 / slot | 参考图位置 `ref_image_0..N` 及用途（实景/造型锚/构图锚/形态参考） |
| 验收点 / acceptance | 一个 clip 的显式通过判据，逐条 pass/fail |
| 版本 / revision | 一次生成或一次 step 的不可变记录（append-only） |
| 替换件 | `parent_clip_id` 指向原 clip 的重跑产物，不覆盖原片 |
| 预算 / budget | 单个 job 的成本上限；穿线即停 |
| Skill | 全局、版本化的提示词规则包，超管维护 |
| lesson | Agent 从失败中自动积累的经验，按作用域召回 |

## 5. 变更纪律

1. 改字段名/类型 = **改 `01`**；改端点/错误码 = **改 `02`**；改数值边界 = **改 `03`**；三者只能在这三处改，代码注释不得另立口径。
2. 破坏性变更（删字段、改语义、改错误码名）须在 PRD 变更记录里加一行。
3. 新增错误码必须同时给：HTTP 状态、`retryable`、用户文案、由哪一层产生。
4. 本目录的数值必须与代码里的 `constants.py` 一致；**常量只有一个来源**，文档引用它，不复制它。
